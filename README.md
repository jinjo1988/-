# 인터벌 운동 타이머

몇 초 운동하고, 몇 초 쉬고, 몇 세트 반복할지 정해서 쓰는 운동용 타이머입니다.
설치나 빌드 없이 `index.html` 하나로 동작합니다.

## 기능

- **운동 / 휴식 / 세트 / 준비 시간** 설정 (− + 버튼을 길게 누르면 빠르게 바뀜, 숫자 직접 입력도 가능)
- 프리셋: 타바타(20/10 ×8), HIIT(40/20 ×10), 서킷(60/30 ×5), 플랭크(45/15 ×4)
- **루틴 모드**: 운동마다 이름·운동 시간·휴식 시간을 따로 정하고(최대 20개) 몇 라운드 반복할지 설정
  - 예: 스쿼트 40초 → 푸시업 30초 → 플랭크 60초 × 3라운드
  - 진행 중 화면과 음성에 운동 이름이 나옴 ("2라운드. 스쿼트 시작", "휴식 15초. 다음은 푸시업")
  - 샘플 루틴: 전신, 코어, 하체
- **내 설정**: 지금 설정(간단·루틴 모두)을 이름 붙여 저장하고 한 번에 불러오기, × 두 번 눌러 삭제
- 진행 중에는 화면 전체가 구간 색으로 바뀜 — 운동은 빨강, 휴식은 청록, 준비는 호박색
- 남은 시간 링, 현재 세트, 전체 남은 시간, 다음 구간 표시
- 구간이 끝나기 3·2·1초 전 삐 소리, 구간 시작 소리, 완료 소리, 진동(지원 기기)
- 한국어 음성 안내: "1세트 운동 시작", "휴식 10초. 다음은 2세트", "마지막 세트", 운동 중 "절반 지났어요"·"10초 남았어요", "셋·둘·하나" 카운트다운, "운동 완료"
  (상단 **음성** 버튼으로 끄고 켬, 끄면 카운트다운은 삐 소리로 바뀜)
- 일시정지 / 계속 / 건너뛰기 / 초기화
- 타이머가 도는 동안 화면이 꺼지지 않음 (Screen Wake Lock 지원 브라우저)
- 설정은 브라우저에 저장되어 다음에 열어도 유지
- 마지막 세트 뒤에는 휴식 없이 바로 완료
- 키보드 스페이스바로 시작 / 일시정지

## 실행

`index.html`을 브라우저로 열면 됩니다.

## 휴대폰에 앱으로 설치

GitHub Pages 주소(https://jinjo1988.github.io/main/)를 휴대폰에서 연 뒤:

- **Android (Chrome)**: 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
- **iPhone (Safari)**: 공유 버튼 → **홈 화면에 추가**

설치하면 주소창 없이 전체 화면으로 열리고, 한 번 열고 나면 오프라인에서도 동작합니다.

> iPhone은 무음 모드에서 소리가 나지 않을 수 있습니다.
> 음성 안내는 기기에 설치된 한국어 음성(TTS)을 씁니다. 한국어 음성이 없는 기기에서는 발음이 어색할 수 있습니다.
